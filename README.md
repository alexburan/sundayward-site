# sundayward.com

The public website for the Sundayward iPhone app: home, privacy policy, support and terms.
Plain HTML and CSS, served by GitHub Pages at https://sundayward.com (DNS in Cloudflare, DNS only).

- `assets/season.js` colours the site by the church year (a port of `season-core.ts` in `alexburan/sundayward-app`).
- No cookies, analytics or third-party requests: the font is served from `assets/`.
- The privacy policy must match what the app actually does. Change them together.
